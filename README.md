# Basic SQL SELECT, WHERE and ORDER BY

A beginner-friendly SQL project demonstrating basic SELECT, WHERE, and ORDER BY queries using a sample employee dataset.

## Task Information

- Task: Task 21
- Track: Data Analytics
- Tools: MySQL / PostgreSQL
- Level: Beginner

## Objective

The objective of this project is to build SQL fundamentals by writing and understanding simple SELECT, WHERE, and ORDER BY queries.

## Dataset

The project uses a sample employee dataset containing:

- Employee ID
- Employee Name
- Department
- Salary
- City

Total Records: 10

## SQL Concepts Covered

1. SELECT
2. WHERE
3. BETWEEN
4. ORDER BY
5. ASC
6. DESC
7. Filtering data
8. Sorting data

## Queries Included

### Query 1
Display all employees.

### Query 2
Display employee names and departments.

### Query 3
Find employees working in the IT department.

### Query 4
Find employees with salary greater than 45000.

### Query 5
Find employees from Delhi.

### Query 6
Find employees with salary between 40000 and 50000.

### Query 7
Sort employees by salary in ascending order.

### Query 8
Sort employees by salary in descending order.

### Query 9
Display IT employees ordered by salary.

### Query 10
Display Delhi employees ordered alphabetically by name.

## Interview Questions

### What does SELECT do?

SELECT is used to retrieve data from one or more tables.

### What does WHERE do?

WHERE is used to filter records based on a specified condition.

### What does ORDER BY do?

ORDER BY is used to sort query results in ascending or descending order.

## Conclusion

This project demonstrates the basic use of SQL SELECT, WHERE, BETWEEN and ORDER BY commands and provides a foundation for further SQL and data analytics learning
